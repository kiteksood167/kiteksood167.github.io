# Blog images

Put photos here. Use lowercase names with dashes, e.g. `phone-camera-closeup.jpg`.

- Size: about 1600 × 900 pixels (16:9), JPG or WebP, under 300 KB each.
- Only use photos you took yourself, or free-licence photos (Pexels, Unsplash, Pixabay).
- Add each one to `index.yml` with a short description so the daily writer can pick a matching photo.
